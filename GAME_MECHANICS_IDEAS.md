# Game Mechanics Ideas

Brainstormed options for replacing/supplementing the crossword (see `STATUS.md` — crossword is currently hidden pending a redesign decision). Organized by role in the overall game loop, not by priority within a tier.

## Tier 1 — Core Gameplay Loop
_Pick 1, maybe 2, to start — don't build all of these._

1. **Swipe-to-match** — word/image or word/translation pairs, timed, Tinder-style swipe left/right
2. **Sentence Scramble Duel** — drag scrambled words into correct order before a countdown ends
3. **Der/Die/Das Sort** — rapid-fire sorting of nouns into 3 buckets, speed increases each round (great for gender drilling, the #1 German pain point)
4. **Match-3 Vocab Tiles** — Candy Crush mechanic where matching tiles reveals translations
5. **Audio Typing Race** — hear the word spoken, type it in German before time runs out
6. **Flashcard RPG Combat** — correct answers = attack a monster, wrong answers = you take damage

## Tier 2 — Progression / Meta Systems
_Gives the loop a sense of "going somewhere."_

7. Skill tree shaped like a map of Germany — unlock regions/cities as you progress
8. XP + character/avatar leveling
9. Streak counter with a "streak freeze" insurance mechanic
10. Spaced-repetition "memory garden" — words are plants that wilt if not reviewed, bloom if mastered
11. End-of-unit boss battle (cumulative review, higher stakes)
12. Mystery reward chest on milestones (cosmetic unlocks, not pay-to-win)

## Tier 3 — Retention / Habit Loops
_Why they open it tomorrow._

13. Daily quest board (3 small tasks, refreshes at midnight)
14. Life/heart system — limited wrong-answer attempts, regenerates over time
15. Smart push notifications (loss-aversion style: "your streak dies in 2 hours")
16. Limited-time themed events (Oktoberfest week, Christmas market vocab, etc.)
17. "Just one more" session hook — end each session on a cliffhanger (e.g., mid-boss-fight, save prompt)

## Tier 4 — Social / Competitive Layer
_Why they come back today._

18. Weekly leagues with promotion/relegation (Duolingo-style)
19. 1v1 real-time quiz duels vs. friends or random opponents
20. Small guilds/squads with a shared XP or streak pool
